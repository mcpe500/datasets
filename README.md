# MiniMax AI Generated Datasets

> Auto-generated AI content using [MiniMax API](https://www.minimaxi.com) via [mmx-cli](https://github.com/natwj/make-minimax-cli). Updated every 5 minutes.

## Overview

This repository contains AI-generated datasets across multiple modalities, collected automatically via scheduled generation cycles. Each file is timestamped and organized by category.

## Categories

| Folder | Model | Description |
|--------|-------|-------------|
| `images/` | `image-01` (50/day) | AI-generated images (512x512–2048x2048) |
| `speech/` | `speech-2.8-hd` (4,000/day) | Text-to-speech audio (MP3, 32kHz) |
| `music/` | `music-2.6` (100/day) | AI-generated music (MP3, 256kbps) |
| `text/` | `MiniMax-M2.7` (unlimited) | Text completions, creative writing |

## How It Works

```
generate.sh (runs every 5 min via LoopCreate)
├── generate_images()    → 3 images per cycle
├── generate_speech()   → 2 speech clips per cycle
├── generate_music()    → 1 music track per cycle
├── generate_text()     → ~20 text completions per cycle
└── git_push()          → commit + push to GitHub
```

## File Naming

```
images/img_YYYYMMDD_HHMMSS_N.png
speech/speech_YYYYMMDD_HHMMSS_N.mp3
music/music_YYYYMMDD_HHMMSS_N.mp3
text/text_YYYYMMDD_HHMMSS_<topic>.txt
```

## Disclaimer

All content in this repository is generated by AI (MiniMax) and may not be factually accurate. Files are stored as-is for research, experimentation, and dataset purposes only.

## Tech Stack

- [MiniMax API](https://www.minimaxi.com) — text, image, speech, music generation
- [mmx-cli](https://github.com/natwj/make-minimax-cli) — CLI interface
- [GH CLI](https://cli.github.com) — GitHub authentication
